# Update Only

This repository is intended to stay focused on Phase 1 until the MVP is stable.

When updating this project:

- Keep creator/session/world terminology throughout the codebase.
- Do not add authentication in Phase 1.
- Do not add a database in Phase 1.
- Do not add paid AI APIs in Phase 1.
- Keep the mock world engine deterministic and easy to inspect.
- Keep setup friendly for new open-source contributors.
